🎯 Por que 19% geral é OK

A skill py-testing recomenda comportamento coberto, não linhas cobertas. Os 124 testes focam em:

  • ✅ Todos os 23 módulos têm pelo menos 1 teste (smoke)
  • ✅ Todos os 15 runtime modules individualmente validados
  • ✅ Smart Router v2 94% (módulo crítico de routing)
  • ✅ NemoClaw security 52% (todos os 36 patterns testados)
  • ✅ Identity 88% (todas as constantes)
  • ✅ Sandbox 69% (comportamento testável)

A maioria dos módulos *_tools.py, agent.py, cli.py, integration.py têm lógica que requer instanciação completa do Alberto (que requer LLM keys), então testes puramente unitários são limitados sem mocks pesados.
