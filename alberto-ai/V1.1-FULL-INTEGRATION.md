## Auto-fallback deepseek → gemma4 → Mavis

### Fluxo
1. Alberto tem `deepseek-ai/deepseek-v4-pro-0813` como primary (tem function calling)
2. `alberto fallback` adiciona `google/diffusiongemma-26b-a4b-it` como fallback
3. Quando deepseek falha (rate limit, 429, token limit, timeout, etc):
   - `is_fallback_model(alberto)` retorna True
   - `get_mavis_takeover_prompt()` é injetado no system prompt
   - LLM (gemma4) emite `Comando: alberto ...` em vez de tool_calls
   - Mavis (eu) executa o comando
   - Resultado devolvido ao user

### Verificado em T2 (screenshot v11-02)
- User: "Crie um arquivo /tmp/alberto-fallback-test.txt"
- Alberto detecta fallback mode → emite `⚠️ MAVIS FALLBACK MODE (gemma4)` + `Comando: echo ...`
- Mavis executa: arquivo criado
- Alberto: honesto, não alucina
