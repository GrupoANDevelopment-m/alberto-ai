# Alberto AI v1.5 — Vision Models + Skill Auto-Invocation + Hermes+NemoClaw Bridge

## Respostas diretas às suas perguntas

### "O Alberto tem skills que permitem acessar internet e usar Chrome?"

**SIM, agora ativados.** Tinha 779 skills carregados mas NÃO auto-invocados. v1.5 adiciona:

**Skill Auto-Invoker** (`skill_engine.py` + `agent.py`):
- 10 regras de pattern matching que detectam intent
- LLM é **automaticamente avisado** qual skill invocar
- Pode chamar via tool `skill(name, input)` direto

**Exemplos testados**:
| Intent do user | Skill detectado |
|---|---|
| "Pesquise no reddit sobre X" | `agent-reach` (15 platforms) |
| "Deploy this app to vercel" | `deploy-to-vercel` |
| "Abra https://example.com" | `browser-skill-click` |
| "Faça um git commit" | `github` |
| "Rode playwright test" | `playwright` |
| "Gere uma imagem" | `flux-2` |
| "Fala isso em voz" | `voice-mode` |
| "Self-heal broken code" | `self-healing-agent` |
| "Oi tudo bem" | (no match — correto) |

**Comandos CLI novos**:
- `alberto auto-invoke "<intent>"` → mostra skill detectado
- `alberto skill run <name> [args]` → executa skill direto

### "Por que não adapta NemoClaw para usar Hermes?"

**FEITO!** Criado `nemoclaw_run_with_hermes()`:

```
NemoClaw provides SECURITY (block SSH/AWS reads, redact secrets)
Hermes provides EXECUTION (terminal, file, code_execution)
Together: safe machine access
```

**Verificado**:
- `cat ~/.ssh/id_rsa` → NemoClaw BLOQUEIA (sem chamar Hermes)
- `cat /etc/hostname` → NemoClaw permite → Hermes executa → retorna OK
- `echo 'nvapi-...'` → Hermes executa → NemoClaw redacta output → retorna seguro
