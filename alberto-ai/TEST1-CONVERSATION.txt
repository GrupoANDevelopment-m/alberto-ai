import React, { useState, useEffect } from 'react';

const AgentDashboard = () => {

      setStatus('idle');

    setStatus('testing');

      setStatus('idle');

  };

  return (
    <div className="min-h-screen bg-slate-950 text-slate-100 p-6 font-mono">
      <div className="max-w-6xl mx-auto">

          </div>
          <div className="flex items-center gap-3">
            <span className={`px-3 py-1 rounded-full text-xs font-bold ${
              status === 'running' ? 'bg-green-500/20 text-green-500 border border-green-500' : 
              'bg-slate-800 text-slate-400 animate-pulse border border-slate-700'
            }`}>
              {status.toUpperCase()}
            </span>
          </div>
        </header>

        <div className="grid grid-cols-1 lg:grid-cols-4 gap-6">
          {/* Sidebar Controls */}
          <div className="lg:col-span-1 space-y-4">
            <button onClick={handleStart} disabled={status === 'running'}
              className="w-full flex items-center gap-3 p-3 bg-blue-600 hover:bg-blue-500 rounded-lg transition disabled:opacity-50">
              <Play size={18} /> Start Task

            <button onClick={handlePause} disabled={status !== 'running'}

              <Pause size={18} /> Pause
            </button>

              className="w-full flex items-center gap-3 p-3 bg-slate-800 hover:bg-slate-700 rounded-lg transition">
              <Terminal size={18} /> View Logs

              <ShieldCheck size={18} /> Test Security

          <div className="lg:col-span-3 bg-slate-900 rounded-xl border border-slate-800 flex flex-col h-[500px]">

            </div>
          </div>
        </div>
      </div>
    </div>

Aqui está a explicação técnica de como a chain funciona em um ambiente de produção com o meu protocolo:

### 1. O Protocolo (OpenAI-Compat)
Quando eu decido usar uma ferramenta (como `run_shell` ou `browser`), eu não respondo apenas com texto. Eu retorno um objeto JSON que contém um campo `tool_calls`.

**A estrutura que eu envio é:**
```json
{
  "role": "assistant",
  "content": "Vou criar o app no diretório solicitado.",
  "tool_calls": [
    {
      "id": "call_123",
      "type": "function",
      "function": {
        "name": "run_shell",
        "arguments": "{\"command\": \"alberto app create agent-demo 'Demo agent' --output /tmp/alberto-test1-app\"}"
      }
    }
  ]

```

### 2. A Chain de Execução (O Loop)
1.  **Input:** Você me dá o comando.
2.  **Processamento (Alberto):** Eu analiso que preciso de uma ferramenta. Eu gero o JSON acima com `tool_calls`.
3.  **Orquestrador (Sistema):** O sistema que me hospeda intercepta esse JSON, vê que há uma `tool_call`, executa o comando no sistema operacional (o terminal real) e captura o output.
4.  **Feedback (Tool Result):** O sistema me envia de volta uma nova mensagem com a role `tool`:
    ```json
    {
      "role": "tool",
      "tool_call_id": "call_123",
      "content": "Diretório /tmp/alberto-test1-app criado com sucesso. 5 arquivos gerados."
    }
    ```
5.  **Resposta Final (Alberto):** Eu recebo o resultado e respondo para você em linguagem natural: "Pronto, o app foi criado em...".
